数据导入 从其他浏览器 / CSV 文件导入

可导入：书签、保存的密码、历史记录（扩展列表 Windows 支持）。入口同时出现在首次启动引导页与设置页（客户端提示词 5.13）。 策略 NodeByteImportPasswordsAllowed / NodeByteImportHistoryAllowed / NodeByteImportBookmarksAllowed 关闭时对应项隐藏。

支持格式：Chrome/Edge 导出（name,url,username,password）、Firefox 导出、Bitwarden 导出（login_uri,login_username,login_password）； 书签（title,url,folder,date_added）；历史（url,title,last_visit_time,visit_count）。列名自动识别。 导入的密码立即写入本机加密 PasswordStore（密钥永不上传），并按同步项勾选状态上传服务端。 也可以在网页个人中心把 CSV 导入到账号，由任意设备登录后拉取（/api/sync/imported）。

同步 同步项勾选（数据类型开关）

同步为客户端 AES-GCM 端到端加密（密钥永不上传）；策略 CustomAllowSync=false 时整个同步入口置灰（本示例按 mandatory 生效演示）。

策略 CustomLockSyncServer=true 时锁定；切换服务器不删除本机任何数据，仅切换上报目标。 可塑性机制：登录、策略、同步、Drop、文件、翻译、TTS 朗读、检查更新、扩展下载—— 全部接口地址都由「当前同步服务器地址」动态推导（优先级：策略指令覆盖 > 此处设置 > 编译默认）， 保存后立即生效并自动重连 WebSocket，无需重启浏览器。

朗读 TTS 语音合成（后端代理，后台可配上游）

上游（自托管 Edge TTS / Azure 语音 / OpenAI 兼容 TTS）由管理员在「后台 → 上游服务」配置， 本端只请求 /api/tts（跟随同步服务器地址）。策略 NodeByteTtsEnabled=false 隐藏朗读入口； 单次合成 ≤ NodeByteTtsMaxChars（默认 3000 字符，长文按句自动分段连续播放）。

加速器 代理与第三方协议

mandatory 下发 ProxyMode 时全灰不可改；recommended 下发默认节点、用户可切换；设备状态经 WebSocket 上报当前代理。

原生协议（HTTP/HTTPS/SOCKS4/SOCKS5）走 Chromium 原生 net/proxy_resolution 栈； VMess/VLESS/Trojan/Shadowsocks 由内核拉起本地 Xray-core（方案 B：配置指向 127.0.0.1 socks5），支持 vless:// trojan:// ss:// vmess:// 链接导入与订阅 URL 更新。 策略 NodeByteAcceleratorEnabled=false 关闭加速器；NodeByteAcceleratorProtocols 限制可用协议；allow_vless_proxy=false 隐藏第三方协议。

此配置由组织管理员管控，不可查看和修改

敏感字段仅 UI 层隐藏：nodebyte://policy 与开发者工具仍可读取内存值（向用户明示，提示词 5.3.3）。

扩展插件 本地安装 / 上传 / 强制下发

Windows：设置页/扩展管理页选择 crx/zip 直接安装； Android：设置 → 扩展 → 「安装本地扩展」，调用系统文件选择器（SAF）选取 crx/zip，内核 ExtensionService 静默安装（需开启「开发者模式」开关，策略 AllowUserSelfInstallExtension=false 时隐藏）。 「上传到同步空间」把 crx 原始包加密上传（EXTENSION_BLOB 类型，计入个人云配额），跨设备恢复时静默重装。

下载源优先级：Edge 扩展商店 → Chrome 网上应用店 → 失败上报错误日志（时间戳/用户/用户组/扩展 ID/下载源/结果/设备 ID）。 访问商店时 HTTP-UA 伪装为对应原版浏览器（策略 CustomSpoofBrowserVendor / CustomSpoofUserAgent）。 策略强制下发的扩展（ForceInstallExtensionPackages / Ids）启用/停用/删除全部置灰，策略移除后自动卸载。

翻译 开源免费翻译 API（多供应商自动降级）

架构：浏览器只请求本后端 /api/translate，后端再按后台「翻译配置」的接口顺序连接上游（密钥仅存服务端）。 默认梯队：Google 免费端点 → Edge 匿名端点 → MyMemory（全部无需 Key）； 管理员在后台可添加 DeepL/百度/有道/腾讯云/阿里云/小牛/Yandex/LLM 等 15 种接口、调整权重、一键测试。 NodeByteTranslateEnabled=false 隐藏入口；单次上限 NodeByteTranslateMaxChars（默认 5000）。

策略 NodeByteTranslateEnabled=false 关闭翻译；NodeByteTranslateAllowAnonymous=false 要求登录后才能翻译。
